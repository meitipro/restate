A refused write still reaches consensus: validators agree the refusal is the right result, and the transaction reads ACCEPTED. The site counts a write as done only when the status is ACCEPTED or FINALIZED **and** the execution returned; otherwise it shows the sentence below, which the transaction carries in its result payload.

`[EXPECTED]` refusals are deterministic and identical on every validator. `[LLM_ERROR]` means a model answer could not be read; validators then disagree on purpose, so the round rotates to a committee that can answer, and nothing defaults to a label. A restatement is never lost to one: it stays waiting, and anyone may call `judge` again.
